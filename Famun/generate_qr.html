⚠️ Importante — URL Base:
Os QR codes acima usam URLs relativas. Quando o site for hospedado (ex: GitHub Pages, Vercel, Netlify), edite a variável BASE_URL no código-fonte desta página para incluir a URL completa do site.

Exemplo: https://seusite.com/ar.html?obra=A

Para usar: Clique "Download PNG" em cada QR code. Os arquivos serão salvos e devem ser colocados na pasta Assets/ do projeto com os nomes qr_A.png, qr_B.png, qr_C.png.
